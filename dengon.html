【録音ができない場合の対処方法】

スマホで録音ができない場合、以下を確認してください。

① LINE の中で開いている場合は録音できません
LINE の Keep やトーク内のリンクから開くと、
LINE 内ブラウザではマイクが使えないため録音できません。

→ 対処方法：
・リンクを長押しして「Chrome で開く」を選ぶ
・または URL をコピーして Chrome に貼り付けて開く

② Chrome のマイク許可が OFF の場合
Android の設定 → アプリ → Chrome → 権限 → マイク → 許可

③ HTTPS で開いていない場合
録音は https:// のページでしか動きません。

上記を行うと録音が使えるようになります。
